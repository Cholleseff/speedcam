# Speedcam

iOS-приложение: карта камер фотовидеофиксации из официальных таблиц Госавтоинспекции и голосовые предупреждения при приближении, в том числе в фоне и при заблокированном экране. Звук идёт в динамики машины через CarPlay или Bluetooth.

## Как это устроено

| Файл | Что делает |
|---|---|
| `scripts/convert_xlsx.py` | превращает xlsx-таблицу ГИБДД в `assets/cameras.json` |
| `src/cameras.ts` | база камер, сеточный индекс, расстояния и азимуты |
| `src/alerts.ts` | логика предупреждений и озвучка |
| `src/tracking.ts` | фоновая геолокация (expo-location + TaskManager) |
| `App.tsx` | карта (Apple Maps), панель со скоростью и ближайшей камерой |

Логика предупреждений:
- дистанция предупреждения зависит от скорости: примерно 18 секунд езды, от 250 до 600 м;
- предупреждает только о камерах впереди, в конусе ±50° от направления движения;
- по каждой камере предупреждает один раз; парные камеры на одной опоре (до 80 м друг от друга) считаются одной;
- после отъезда от камеры дальше 900 м она снова может вызвать предупреждение.

## Обновить базу камер

1. Скачайте свежую таблицу региона на https://госавтоинспекция.рф/r/26 (раздел про места установки средств фотовидеофиксации).
2. Выполните:
   ```bash
   pip install openpyxl
   python -I scripts/convert_xlsx.py "путь/к/таблице.xlsx" --region 26
   ```
3. Пересоберите приложение.

## Сборка .ipa без Mac (GitHub Actions)

1. Создайте репозиторий на GitHub (публичный: для него минуты macOS бесплатные) и запушьте проект.
2. Откройте **Actions → Build iOS (unsigned) → Run workflow**.
3. Минут через 15–25 скачайте артефакт `Speedcam-ipa`. Внутри zip лежит `Speedcam.ipa`.

## Установка на iPhone (Sideloadly, бесплатный Apple ID)

1. Установите iTunes (с сайта Apple, не из Microsoft Store) и [Sideloadly](https://sideloadly.io) на Windows.
2. Подключите iPhone кабелем и нажмите «Доверять этому компьютеру».
3. Перетащите `Speedcam.ipa` в Sideloadly, введите Apple ID (лучше отдельный, не основной) и нажмите **Start**.
4. На iPhone откройте **Настройки → Основные → VPN и управление устройством**, найдите свой Apple ID и нажмите «Доверять».
5. На iOS 16 и новее включите **Настройки → Конфиденциальность и безопасность → Режим разработчика** и перезагрузите телефон.
6. С бесплатным Apple ID подпись живёт **7 дней**. Потом повторите шаг 3, данные приложения сохранятся.

## Использование

1. Нажмите **«Поехали»** и разрешите геолокацию, затем выберите **«Всегда»**. Без «Всегда» предупреждения работают, только пока экран открыт.
2. Кнопка 🔊 проверяет звук.
3. Приложение можно свернуть или заблокировать экран. Сверху будет гореть синий индикатор геолокации.
4. **Не смахивайте приложение из переключателя приложений**: так iOS останавливает фоновую работу.

## Разработка

```bash
npm install
npx tsc --noEmit
npx expo-doctor
```

Expo Go фоновую геолокацию на iOS не поддерживает, поэтому проверять фоновый режим можно только на собранном `.ipa`.
